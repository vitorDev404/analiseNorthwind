#Análise de Produtos - Northwind

Projeto desenvolvido em C# utilizando SQL Server, CSV e Programação Orientada a Objetos.

##Objetivo

Realizar consultas SQL no banco Northwind, exportar os dados para CSV e processar as informações utilizando C#.

---

##Tecnologias utilizadas

- C#
- .NET
- SQL Server
- CSV
- Visual Studio

---

##Funcionalidades

- Leitura de arquivo CSV
- Listagem de produtos
- Produto mais vendido
- Produto menos vendido
- Menu interativo no console
- Organização em múltiplas classes
- Estrutura orientada a objetos

---

##Query SQL utilizada

A consulta realiza:

- JOIN entre tabelas
- SUM de vendas
- GROUP BY
- ORDER BY

---

##Estrutura do Projeto

- `Produto.cs` → Modelagem da entidade Produto
- `AnaliseCsv.cs` → Regras de negócio e leitura do CSV
- `Program.cs` → Menu principal
- `QuerySQL.sql` → Query SQL utilizada
- `Resultados.csv` → Dados exportados
